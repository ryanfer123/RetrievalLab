How these results are calculated

BM25 uses k₁ = 1.5 and b = 0.75 with a positive IDF. TF-IDF uses log term frequency, smoothed IDF, and cosine similarity. Both tokenize Unicode words, fold case, and break ties by document ID. Neither uses embeddings, stemming, or language models.

Relevance is binary. nDCG rewards relevant documents near the top; reciprocal rank uses the first relevant result; recall measures coverage; precision divides relevant hits by k. Zero-score matches are omitted. Latency measures the search call, excluding index construction, database work, and network time.
